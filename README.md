# 🔎 Медіадетектив — місячник медіаграмотності 2026

Окремий інтерактивний освітній сайт для **Великогрибовицького ліцею**. Призначений для учнів **5–11 класів** та педагогів. Усі кейси вигадані і використовуються лише для навчання.

## 🔗 Посилання після увімкнення GitHub Pages

https://yuriiostafiichuk.github.io/media_knowledge/

> Якщо бачите 404, відкрийте **Settings → Pages** репозиторію та увімкніть публікацію з гілки main (інструкція нижче).

## Що всередині

- 16 інтерактивних уроків: **4 теми × 4 аудиторії** (5–6, 7–8, 9–11 класи, педагоги).
- Кожен урок: життєвий кейс, три інтерактивні підказки, тест із 3 запитань, пояснення відповідей, висновок і сценарій для класного керівника.
- Чотири тижні грудня: **1–4** (фейки), **7–11** (ШІ / дипфейки), **14–18** (фішинг), **21–24** (соцмережі / вплив).
- Рекомендована тривалість одного заняття: **15–20 хв**.
- Режим для смартфона й для демонстрації з проєктора, кнопки друку й копіювання прямого посилання на урок.
- **Без реєстрації, трекерів, аналітики, серверів, cookies, зберігання відповідей або персональних даних.** Після оновлення сторінки тест починається спочатку.

## Публікація через GitHub Pages

1. Відкрийте [Settings → Pages](https://github.com/YuriiOstafiichuk/media_knowledge/settings/pages).
2. У **Build and deployment → Source** виберіть **Deploy from a branch**.
3. У **Branch** виберіть **main**, а директорію **/(root)**; натисніть **Save**.
4. Дочекайтеся зеленого статусу розгортання на сторінці Pages (час публікації залежить від GitHub).
5. Перейдіть на адресу https://yuriiostafiichuk.github.io/media_knowledge/.

Сайт не потребує npm, Vite чи GitHub Actions: GitHub Pages публікує статичні файли без збірки.

## Використання класним керівником

1. Відкрийте сайт на інтерактивній дошці чи комп'ютері з проєктором.
2. Оберіть вікову групу та тиждень.
3. Відкрийте урок. Прочитайте ситуацію, запропонуйте класу знайти підозрілі деталі.
4. Розгорніть три підказки; пройдіть тест разом із класом або дайте учням посилання для проходження на телефонах.
5. Використайте запитання для обговорення й узагальніть основне правило.
6. Персональні результати дітей **не фіксуються**. Для звітності заклад може окремо зафіксувати проведення заняття без персоніфікації.

**Важливо:** не просіть дітей повторювати шахрайські дії, розкривати особисті дані, вводити паролі або відкривати підозрілі URL. Домени *.example у навчальних кейсах — приклади, не посилання для переходу.

## Структура

| Файл | Що містить |
| --- | --- |
| `index.html` | Оболонка сайту, навігація, ресурси |
| `styles.css` | Адаптивний дизайн, візуалізація кейсів, стилі друку |
| `content.js` | Тексти всіх уроків, підказки, питання й відповіді |
| `app.js` | Логіка карток, навігації, квізів, копіювання посилань |
| `favicon.svg` | Піктограма |

## Редагування контенту

Зміни до уроків робіть у `content.js`: кожен об'єкт `lesson(...)` описує один кейс. Порядок відповіді у `q(question, options, correct, why)` відраховується з **нуля**. Наприклад, `correct=1` — другий варіант.

Для локального перегляду можна просто відкрити `index.html` у браузері. Рекомендований варіант для перевірки навігації й копіювання: `python -m http.server 8000` у папці проєкту, а потім http://localhost:8000/.
